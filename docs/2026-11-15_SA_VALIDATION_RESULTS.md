# S/A实机验证：结果、范围与剩余阻断

> 本报告记录首批8局实验的冻结结果。基于已核对的远程版本 `24d7e4a`。
> 本轮更新仅三份文档，不包含验证源码、Mod、存档或原始对局数据。

## 当前结论

**本地独立验证副本已形成可运行的实验交互与证据闭环；训练输入及旧训练工程尚未全部准入。**

本轮使用静默猎手A20、确定性测试启发式推进隔离对局。驾驶员先生成S，再按A掩码选动作，绑定同一快照执行，保存动作回执及后继状态。独立原生观察器用于交叉对照，并分别记录部分动作实际进入游戏方法的见证。

这是状态与动作的准确性实验。测试启发式的终局成绩不能当作神经网络通关能力，也不能作为NoSL胜率评测。

## 四层验收不能互相替代

| 层次 | 核验问题 | 可以支持的结论 | 不能据此推导 |
| --- | --- | --- | --- |
| 传输与转换 | raw、对象与向量是否对应；字段是否丢失 | 已保存数据可以复现，已比较公开字段一致 | raw本身一定正确、所有必要信息都已采集 |
| 实际调用 | 命令是否进入正确的游戏方法、牌槽与目标 | 对应调用入口确实发生 | 效果已结算完成 |
| 最终效果 | 伤害、格挡、药水或奖励结果是否落地 | 有完整前提的具体效果可逐项验证 | 其他机制或所有效果也正确 |
| 状态充分性 | 可知决策因素是否完整保留 | 已验证机制子集中的具体充分性结论 | 单帧S已覆盖全游戏 |

raw与向量由同一规则生成时，二者相同只能证明传输或实现一致，不能单独证明raw正确。因此保留独立原生对照、来源窗口、歧义和未覆盖项。

## 本地已修复的主要问题

| 范围 | 实验实现 | 仍需保留的边界 |
| --- | --- | --- |
| 状态对象 | 保留原始动态字段、槽位、缺失及null | 未知字段保留用于诊断，不自动进入策略 |
| S的语义 | 对象身份与槽位绑定；区分空槽、未知、隐藏和实际0 | 未支持实体、容量溢出和无法绑定的选择明确拒绝 |
| 敌人 | 单次伤害、次数、powers和死亡/逃跑阶段分别表示 | 意图受原生显示门槛控制，门控未知即屏蔽 |
| 卡牌与历史 | 基础数值、当前费用、目标口径及同帧已核验历史 | 缓存值不冒充逐目标最终伤害，未知历史不伪造为0 |
| 地图与选择 | 地图钥匙标记与已持有钥匙分开；HAND_SELECT公开提示与条件入S | 已遇GRID/事件只按实际字段验收，未遇特殊商店分支继续未覆盖 |
| 动作与step | 修正药水目标口径、确认/跳过掩码；接通真实step及快照绑定 | 入口记录与最终效果分别验收，不自动重发不确定动作 |
| 延迟结算 | 奖励卡入库及战斗意图未稳定时，有限查询后确认 | 查询不是重发动作；失败保留为未确认，不重放战斗 |

S只接收明确的公开字段。隐藏抽牌顺序、种子/RNG、内部下一招和未来问号房内容不进入策略。必要的公开历史与位置记忆不能以“不是当前面板值”为由排除。

8局实验已结束：3探索局、5冻结局，共1742个驾驶员动作。以下5局使用同一冻结源码和运行模块，共1005步、1053raw帧，全部在第一幕死亡；最远到第一幕Boss，没有通关或第二幕以后的认证。

- 独立原生对照：667个不同稳定决策点，各局116/110/217/161/63，均超过事前20个要求。102020次已接受字段比较一致；257帧核心歧义保留。全局匹配范围未发现字段差异，不能代表全部状态无误。
- 60个HAND_SELECT公开提示/条件状态全部匹配；22次奖励卡的驱动最终状态均包含正确卡牌；147次结束回合中141次前后端可全局配对。
- 原生调用见证：578次匹配（553出牌、22奖励选牌、3药水），427次动作未接入这些调用入口。344步联合证据成立但仍带覆盖缺口，661步未联合通过。正式五局未发现调用身份矛盾或窗口内显式状态字段差异；不等于完整因果/效果认证。
- 保存记录回放：1005步、2010个S前后端点、46410项检查，0差异、0复现资料缺口。650个端点的unknown history原样保留，1360个端点仅按已保存计数复现。
- 280项Python回归和10项独立回放负向测试通过。终局空闲239.5秒，原始状态、请求日志、原生记录均未变化；此检查限于终局，不冒充新的战斗静置测试。

**分层结论：已测采集、控制与回放链通过对应检查；全机制S充分性、完整效果及训练准入未通过。** Setup在本批实际出现，但其可知牌堆位置记忆尚未支持，相应数据明确阻断；未出现的Necronomicon等不能默认通过。

保存记录回放分别比较：每步S/S_next与归档raw重新编码的逐元素结果、raw经GameState转换后的全字段、动作ID/命令/语义、合法动作掩码及快照哈希。history只按保存的原上下文复现，不把这条循环当作新的原生真值证明。缺元数据记unknown，不使用默认值凑齐。

每局还须列实际遇到的屏幕、实体和机制。五局运行成功或未发现差异，不能替代未出现机制的证据。

三局未匹配项为握手帧。版本不同，不能合并为S5新增字段的通过率。准确措辞是：**已接受的配对未见字段差异**，不能概括成“所有状态0差异”。

explore-02的204步中，112步有匹配的原生调用入口见证：106次出牌、5次奖励选牌、1次药水调用；另92步未覆盖当前入口布点。其中96步还满足部分状态、掩码和回执联合条件，但仍带状态覆盖缺口，其余108步未形成这组联合证据。调用记录保持 `settled=false`，不视为完整效果证明。

奖励方面，explore-01的6次与explore-02的5次选牌，在后续牌库观察到所选实例；后者5次还经过延迟入库确认。这证明这些奖励结果被观察到，不能替代其他动作的效果核验。

普通牌方面，explore-02的44个Strike/Defend样本（16个Strike、28个Defend）中，288项能量、HP及格挡数值相符，未见数值差异。但 `freeToPlayOnce`、`Settings.isDebug`、`stance`、`damageTypeForTurn`等原生前提未采集，标签保持“数值相符，但部分前提未观测”。**完整效果验证数量为0**，不能升级为完整S充分性。

## 已发现的实际对时不足

explore-03的raw170牌库为17张，同一动作窗口的native430为16张，涉及Flying Knee；记录间隔约12毫秒。step160/161的联合验收拒绝。全局配对将该帧归入歧义，而不是字段mismatch，因此“已接受配对差异为0”不能掩盖这类拒绝项。

原生431的毫秒时间区间跨越raw接收截止，被冻结的动作窗口规则排除；该记录已含新增牌，但不能回填来通过。采样时机与时间精度导致的对齐歧义尚未消除。当前不能自动认定哪一层正确，也不能只选一个有利候选让它通过。该例表明独立来源的因果绑定仍需加强，相关样本不得进入训练。

## 训练准入前的剩余事项

1. 消除动作与原生快照的采样边界歧义，保留已经完成的五局审计和拒绝样本。
2. 在有限机制范围内补齐卡牌动态效果的公开前提，并验证实际结算；缓存值不直接作真值。
3. 对必要机制状态逐ID准入：未解释的power.misc、Necronomicon触发状态，以及Setup/Forethought公开牌堆位置记忆，继续作为明确覆盖阻断。
4. 只接受同快照、独立核验通过的历史计数。缺口可供实验定位，不能自动升级训练准入。
5. 单独迁移旧数据标签、网络布局、预处理和权重接口；用少量合格样本验证训练读写、损失与回放后，再讨论规模训练。

后续可以声明的范围是“已验证的公开字段和机制子集”，不承诺全游戏100%覆盖。当前没有神经网络能力评测结果，也没有整个训练工程已统一的结论。
