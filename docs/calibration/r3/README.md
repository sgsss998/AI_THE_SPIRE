## 下一轮最先要补什么

1. 从模型开局漏掉的“诅咒＋双变牌”入手，取得真机两个候选选择及确认后的牌组，再把同种子交给模拟器核对。
2. 用原版逐帧确认蛇事件到账时点，分别检查接受、点继续、离开三步的金币和永久牌组。
3. 用当前仍停住的菌兽、选牌和奖励病例扩充真实合法动作证据；训练准备度继续按可操作范围、终局数和配对轨迹评估。

本地版有独立入口和封存清单。核验用项目 Python 执行 `python -m experiments.sa_calibration_round3.verify_release`，项目运行路径包含 `scripts:src:build:.`。原始真机和模拟轨迹、证据提取器、最终接口、自由回归结果分别保存。
