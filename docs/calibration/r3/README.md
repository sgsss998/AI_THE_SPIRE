# 静默猎手 A20 状态与动作校准 · 第三轮

## 已核对的起点

第二轮固定 640 局中，333 局由游戏判定阵亡，307 局在模拟器对模型开放的接口上停止。额外 64 局为 22 局阵亡、42 局接口停止。第二轮增强输入有 3,122 个状态值和 193 个动作编号，包含当前隐藏堆顶与古老茶具的开战充能。基线文件 SHA-256 为 `428c2d830023a430f1dc46829b64d34a0e13bce206d58cf87cd977d287ea3f90`。

原版自行生成的种子 `3KGW38IEQVW1B` 已由模型接口重放至第 3 层阵亡。排除奖励页重复往返，98 次输入覆盖 101 个原版画面，已查 1,415 项公开字段组一致。另有两条历史路线经独立底层动作核对，分别复现至第 16 层守护者和史莱姆老大阵亡。这两条路线在模型接口上仍有动作缺口。

## 本轮进度

已从冻结轨迹按进入选牌的事件来源、任务类型、要求数量和死亡怪物的原始位置筛出 53 个不同种子。各行保留原始轨迹的 SHA-256。

| 原来停住的场景 | 固定种子数 | 验收方法 |
