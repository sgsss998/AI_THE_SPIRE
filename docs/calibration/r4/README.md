# 静默 A20 第四轮校准

基线为 R3 的 e24f784，已重建并核对 89 份封存文件。R3 模拟 704 局，其中 374 局由游戏判定阵亡，330 局遇到接口停点。种子 35LAE5197HT9L 本轮作为开发用回归。第四轮盲测将在冻结模型后由原版另行生成种子。

已从同种子、同一系列输入回放固定组全部 76 个选牌停点和 53 个奖励停点，通过引擎原始候选核对到 23 组。每个停点的前后两帧均与封存状态逐项比对。选牌中，活墙三个选项合计 20 局、营火升级 14 局、涅奥换星盘三选 8 局。奖励中，普通战后 19 局、实验室药水 10 局、蓝衣女子药水 8 局；召唤铃铛和小屋另有 7 局与 6 局。这些数字用于选择下一批原版试验，不能当作已修的局数。

涅奥双变牌、菌兽死亡和蛇事件分别采集、校准。后续将补充独立实机证据、正式接口结果、整批回归和原版新随机局。
