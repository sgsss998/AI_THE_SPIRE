## 同种子正式重放

本轮将 R4 的真机随机种子 **2W47ZBJ8TBFMD** 用作开发用例。R4 原局共 339 次有效输入，第 16 层阵亡。R5 从头只用模型正式入口连续执行，前 128 次真机输入已走完。其中包含真机确认弃牌时实际打出的两张打击；纯翻页逐条登记。

- 第 98 次实际领取墨水瓶成功。此后第 111、126 次操作中的墨水瓶计数都从 9 归零，所查手牌与原版一致。
- 第 128 次打完邪教徒，真机给出 20 金、再生药水和一份选牌，模型显示空奖励页。第 129 次真机选择金币，模型没有可执行的选项。这一处同时影响 S 和 A。

这次使用修复时已看过的种子。本轮没有新增一局用留空种子开局的独立盲测。[R4 对照](r4-replay.json) · [R5 逐步重放](r5-replay.json)

## 还需多久

以仍未结的 17 个登记分支为单位，参照上轮约 41 分钟的并行工作窗口，若每个窗口结清 2–3 项，约需 4–6 小时；若每项要反复进入真机、取证和开发 1–3 个窗口，约需 12–35 小时。这是当前台账的工作量情景。后两幕首领、胜利路线和稀有组合仍缺逐步实机证据，全游戏验收的总工期暂不能从这 17 项外推。[估算口径与证据缺口](coverage/REPORT.md)
