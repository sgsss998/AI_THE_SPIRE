# 第九层宝箱三种选择

种子 `2W47ZBJ8TBFMD`，静默猎手 A20。真机沿原路线进入第九层宝箱，先拿 81 金。选择遗物时角色有 56/66 血、237 金，两个药水槽均空。正式 R5 的同一组状态值能读出墨水瓶以及与它互斥的蓝钥匙，模型可选拿遗物、拿钥匙或继续。三条路线均从头经过正式 R5，不调用诊断接口或写入模拟器状态。

| 第 98 次选择 | 真机选择后的结果 | 再次决策的位置 |
|---|---|---|
| 拿墨水瓶 | 遗物入包一次，计数为 0，未获钥匙。遗物和钥匙两行同时消失。 | 从空奖励页继续，地图坐标 (2,8)，下一个可选位置为 x=2。 |
| 拿蓝钥匙 | 两行同时消失，未获遗物。蓝钥匙图标在领取动画后生效。 | 快速离开与等待后离开均到同一地图和下一可选位置。 |
| 直接离开 | 遗物和钥匙均未获得。 | 直接到同一地图，下一可选位置相同。 |

三条路线的生命、金币、牌组、遗物、药水和下一可选地图位置都逐项核对。只有蓝钥匙标记有瞬时时差。快速离开时，原版领取回执和地图首帧的标记均为假，下一条原生状态记录变真，期间没有游戏输入。复测中留在空奖励页，只查询状态，立即回执仍为假，0.368 秒后收到的首次查询结果为真，此后一直为真至离开。在空奖励页唯一可改变进程的操作是继续。正式 R5 在一次领奖动作结束时即给出最终的钥匙标记。两种原版操作速度在本次地图获得相同可选下一步。

同一宝箱内奖励会换位置。领取金币前，模型的 A110 是 81 金，A111 是墨水瓶。金币入账后，墨水瓶移动到 A110。额外的模型测试在拿金币前选 A111，墨水瓶成功入包，81 金仍可领取。每个实机选择对应的旧模型操作回执均已验证不能重复使用。

采集时用独立原版实例重走已知种子。首次重走在第 10 次确认弃牌时未自动打出上轮真机的附带打击，到第 33 次仍在战斗。另一实例按该次和第 66 次的原版出牌回调核对附带动作，成功走到第九层。保存第九层游戏自己写出的存档，蓝钥匙快速路线沿原局继续，其余路线通过原版“继续”读取同一份存档。存档散列、逐次输入和原生读数可在结果中查阅。此次实验结束后已关闭对应游戏窗口。
