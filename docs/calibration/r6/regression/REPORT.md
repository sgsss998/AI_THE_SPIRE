# R6 固定策略 704 局回归

静默猎手 A20，同一组 640 个固定种子和 64 个补充种子，逐局沿用 R5 的决策上限和选动作策略。每次从空白对局启动，使用本版公开动作接口。两版都没有超过决策上限的局。

| 结果 | R5 | R6 |
| --- | ---: | ---: |
| 走到阵亡 | 372 | 372 |
| 模型没有可执行动作 | 332 | 332 |
| 上述停点中的奖励页 | 58 | 57 |
| 上述停点中的牌组选牌页 | 91 | 92 |
| 全组总操作数 | 62,352 | 62,413 |
| 到达的最高层 | 11 | 11 |

703 局的操作序列逐步一致。种子 9000033 在第 1 层的前 31 个输入完全相同；第 32 次决策时，原先空白的奖励页提供了领 20 金、领药水、进入选牌和离开四项。固定策略领了金币后离开。这局从原先的 31 个操作走到 92 个操作，最终在第 5 层「活墙」事件选择第一项后停在牌组选牌页。此时还有 23 点生命，模拟器本体列出了 13 张可选的牌；动作接口尚不能核准这次选牌的来源以及每一张牌对应的动作。

640 局固定组中，348 局阵亡，292 局接口停住。64 局补充组中，24 局阵亡，40 局接口停住。372 局阵亡样本中，349 局曾经过部分动作尚待验证的页面。这次全组回归衡量模拟器接口的可运行程度，原版同种子的逐步一致性另有实验。
