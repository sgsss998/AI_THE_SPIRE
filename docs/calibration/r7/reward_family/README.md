# 普通战后领奖

第六轮的 57 个奖励停点中，有 9 个已经可以领奖或直接离开。同一种子沿原动作到达旧停点后，两条路线分别领完奖励和放弃全部奖励。逐步检查金币、药水槽、三张候选牌和永久牌组，直到回到可选路线的地图。其余 48 个旧停点仍然存在。

袖剑种子 7000047 另有两份单独取得的真机记录。一条拿金币、药水和卡牌，一条在选牌时丢掉已拿的药。两条路线的 13 个奖励或地图画面均按真机记录复核，回到地图均为 114 金和 14 张牌。光滑石种子 54072729 的原版第 11、12 层也有完整交易收据。当前从头重放这颗种子仍提前停在另一页，两个原版片段单独列出。

第二幕第 18 层从真机战前存档开始，同一组 30 个实际输入重放到了三张奖励牌展开。战斗结束时，真机苦无计数从 1 变为 −1；模型保留这个变化，同时展示 11 金和卡包。原始操作到打开奖励牌为止。
